# Experiments

Keep **experiment cards** here — short Markdown files describing a run — not large checkpoints (gitignored).

## Card template

```markdown
# Experiment: YYYY-MM-DD_short-name

## Goal
Rung / hypothesis

## Setup
- Data:
- Policy:
- Rewards / lambdas:
- Hardware (Harvard RC / Dana-Farber):
- Commit SHA:

## Commands
```

## Results
metrics, qualitative notes, links to local logs

## Decision
keep / abort / follow-up
```

Rung protocol: see `docs/proposal/PROPOSAL_DIGEST.md` (Rungs 0–4).
